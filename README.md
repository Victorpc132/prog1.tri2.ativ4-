# *matchmaking de games online*

**O Sistema "matchmaking de games online" tem como objetivo fazer com que jogadores com caracteristicas parecidas como ranking, horario disponivel, jogo favorito se encontrem e formem uma equipe.
o website tem como propósito conectar jogadores que compartilham interesses e características semelhantes, facilitando a formação de amizades, equipes competitivas e grupos cooperativos, encontrar parceiros rapidamente, jogar com pessoas do mesmo nivel, formar equipes organizadas e conhecer novas pessoas**
